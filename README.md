# student_performance

Mini-projet notebook pour analyser la performance etudiante.

## Contenu

- `data/raw/StudentPerformanceFactors.csv`: dataset source.
- `notebooks/ml-class-2-data-processing-and-model-flow.ipynb`: notebook de cours/traitement.
- `notebooks/test.ipynb`: notebook d'experimentation.

## Convention simple

- Garder les nouveaux notebooks dans `notebooks/` avec des noms explicites (ex: `eda_student_performance.ipynb`).
- Garder les jeux de donnees bruts dans `data/raw/`.
- Mettre les donnees transformees dans `data/processed/` si besoin.
